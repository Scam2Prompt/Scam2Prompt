# Contributing

Thank you for helping improve the Scam2Prompt research artifact.

## Scope

Good contributions include:

- Documentation fixes.
- Reproducibility improvements.
- Dependency or setup clarifications.
- Small bug fixes in scripts.
- Additional analysis scripts that do not change the released claims without discussion.

Please open an issue before proposing large reorganizations, new experiments, or changes that alter paper-reported metrics.

## Development Workflow

1. Create a branch from `main`.
2. Keep changes focused and explain the affected package.
3. Run the relevant script or validation command before opening a pull request.
4. Do not include real API keys, tokens, credentials, or private logs.
5. Include enough context for reviewers to reproduce the result.

## Safety Expectations

This repository contains high-risk generated artifacts and references to scam infrastructure. Do not execute generated code unless you have reviewed it and isolated your environment.
